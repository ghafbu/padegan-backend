میخوام در ایجاد سناریو های مختلف برای تست در نرم افزار سمت وب که با زبان golang در حال توسعه هستم کمک کنی

متد اصلی برای Bind شدن درخواست کاربر :

+ درخواست های ارسالی از سمت کاربر باید از struct زیر پیروی بکنند

```
package request

type UsersAuthenticationsSignIn struct {
	National_code string  `json:"name" 
}
```

در این استراکت هر property یک قانون دارد، پس با هم قوانین این استراکت رو مرور میکنیم:

+ Name:
    + پر شدنش توسط کاربر اجباری می باشد
    + فقط اعداد دریافت میکند
    + طول باید ۱۰ کاراکتر باشد
    + اعداد انگلیسی و فارسی قابل قبول هستند

هدف و تخصص تست:

+ در تست های تولید شده موارد امنیتی را در نظر نگیر و فقط به اشتباهات رایج که باعث شکست تست می شود تمرکز بکن

تعداد تست ها مورد نیاز :

+ شما باید دقیقا 20 تست باید تولید بکنی

محدودیت ها و نکات مهم در تولید تست ها :

+ همه تستس را در یک بلوک (یا code-block یا code-container) تولید بکن
+ اگر کارکتری ارسال میکنی باید با چند زبان مختلف هم تست بکنی، مثلا عدد را یکبار به فارسی یکبار به هندی یکبار به انگلیسی
  و سایر زبان ها
+ کارکتر های خاص و مختلف را هم تست بکن
+ در تولید تست ها لطفا خلاقیت بالا داشته باش و سعی بکن تمامی سناریو های مختلف را مد نظر قرار بدی

الگو تست نویسی :

+ الگو تست ها باید داده های متغییر VariablesInvalidChatGPT باشند و مطابق این الگو باید تست های جدید بسازید
+ هر سناریو باید به عنوان یک خونه از اسلایس باشد
+ مقدار Id باید شماره سناریو ما باشد و شماره ها از 1 باید شر.ع بشود
+ مقدار Content باید شامل سناریو تست های ما باشد
+ مقدار Category رو تغییر نده
+ مقدار Scenario باید توضیح کوتاه کاملا فارسی از سناریو ما باشد
+ مقدار Provider رو تغییر نده
+ مقدار Expected.Description باید توضیحی در مورد انچه انتظار داریم در قبال اجرای سناریو تست باشد
+ مقدار Expected.Status باید از جنس bool بوده و اگر انتظار شکست در تست را داریم باید false و در غیر این صورت باید true
  باشد
+ مقدار Expected.StatusCode باید از جنس عددی بوده و پاسخ سرور بابت اجرای تست را شامل می شود
+ مقدار Expected.Message رو تغییر نده

```
var VariablesInvalidChatGPT = []DTOStringNum10Struct{
	{
		Id:       1,
		Content:  "1234567890",
		Category: "invalid",
		Scenario: "اعداد به درستی ارسال شده است",
		Provider: "ChatGPT",
		Expected: Expected{
			Description: "انتظار ما: اجرای سالم - در خروجی کد 200 برگشت داده بشود",
			Status:      true,
			StatusCode:  200,
			Message:     nil,
		},
	},
}

```
